# PowerChain Copilot Mobile Documentation

Version 1.0.0

The canonical product documentation is published through `apps/docs/` and the generated whitepaper in `public/assets/`.

## Documentation surfaces

- Mobile UX and information architecture
- RWA agent architecture
- PWRC Credit Kernel
- Solana Pay settlement verification
- Security and human approval controls
- External standards and references

Run the docs application with:

```bash
pnpm docs:dev
```

Build the static documentation site with:

```bash
pnpm docs:build
```
