# PowerChain verified icon integration

This directory is the canonical export pack for PowerChain Copilot Mobile 1.0.0.

- `masters/` — iOS appearance icons and transparent brandmark masters
- `ios/` — AppIcon asset catalog exports
- `android/` — adaptive, monochrome, notification and density resources
- `web/` — favicon, Apple touch, PWA, maskable and Windows tile resources
- `store/` — App Store and Google Play artwork
- `desktop/` — Electron, Tauri and Linux PNG/ICO exports

The emblem geometry is sourced from the supplied PowerChain artwork rather than redrawn.
