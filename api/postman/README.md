# Postman

Import `powerchain-capilot.postman_collection.json` and one environment file.

- `powerchain-local.postman_environment.json`
- `powerchain-devnet.postman_environment.json`
- `powerchain-mainnet.postman_environment.json`

The collection contains no credentials. Set `accessToken` locally after login. Payment Kernel HMAC variables are intentionally blank and must only be generated by trusted server-side tooling.
