# PowerChain Copilot Mobile Skills

Skills are declarative operator workflows. Every skill must state required evidence, allowed read tools, output type, and whether it prepares a Safe Action. Skills never sign transactions, approve their own work, or represent simulation as live telemetry.

Core skills: site health review, live-flow validation, alarm triage, asset evidence review, settlement readiness review, PWRC credit diagnostics, Solana/Sui configuration diagnostics, and report/snapshot export.
