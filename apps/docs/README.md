# PowerChain Copilot Documentation App

Static Next.js documentation surface for the PowerChain Copilot mobile application.

## Routes

- `/` — product and architecture overview
- `/mobile` — mobile information architecture and UX
- `/architecture` — RWA agent and execution model
- `/credits` — PWRC Credit Kernel and Solana Pay flow
- `/security` — trust boundaries and release controls
- `/references` — external standards and canonical source references

The app reads static assets from `apps/docs/public/`, synchronized from the repository-level `public/` directory.
