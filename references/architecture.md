# Architecture reference

PowerChain Copilot follows an evidence-to-execution model:

1. authenticated operator context;
2. Copilot and RWA orchestrator planning;
3. specialized agents and skills;
4. evidence, policy and risk checks;
5. explicit human approval for high-impact actions;
6. wallet signing;
7. verified blockchain or external settlement.

The mobile client is not authoritative for balances, settlement, transaction completion, telemetry, or evidence freshness.
